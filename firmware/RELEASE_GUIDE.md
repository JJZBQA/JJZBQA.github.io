# 固件Release管理规范

## 版本策略

### 方案一：按时间统一发布
- 版本格式：`vYYYY.MM` (如：v2024.02)
- 包含该月份所有设备更新
- 适合固件更新频率较低的情况

### 方案二：按设备独立发布
- 版本格式：`设备名-版本号` (如：BM2-V1.2)
- 每个设备独立版本管理
- 适合频繁更新的场景

## 文件命名规范

```
设备类型_型号_版本.扩展名
例如：
- camera_BM2_V1.2.bin
- router_TL-WR841N_v3.2.1.bin
- iot_SmartPlug_v1.5.0.bin
```

## Release描述模板

```
## 固件更新 (2024年2月版)

### 📷 摄像头固件
- 文件：camera_BM2_V1_2.bin
- 更新内容：优化夜视效果，提升连接稳定性

### 🌐 路由器固件  
- 文件：router_TL-WR841N_v3.2.1.bin
- 更新内容：修复安全漏洞，改善WiFi性能

### ⚡ IoT设备固件
- 文件：iot_SmartPlug_v1.5.0.bin
- 更新内容：新增定时功能，优化能耗统计
```

## 下载链接管理

在JSON中维护两种链接：
1. `download_url`: 本地相对路径（用于网站内部）
2. `direct_link`: GitHub Release直接下载链接
